About MeTentang Saya

Halo, saya Arta, mahasiswa Sains Data di Politeknik Elektronika Negeri Surabaya (PENS). Saya tertarik pada satu pertanyaan sederhana: bagaimana data bisa benar-benar berguna bagi orang? Pertanyaan itu yang membawa saya belajar dua hal sekaligus, yaitu analisis data dan rekayasa backend.


Menurut saya, model yang akurat belum cukup kalau tidak bisa diakses. Karena itu saya terbiasa mengerjakan project dari ujung ke ujung: membersihkan dan memahami data, membangun model, membungkusnya dalam API, lalu men-deploy-nya ke cloud menggunakan Docker agar bisa dicoba langsung.


Saat ini saya sedang mendalami integrasi Large Language Model ke aplikasi nyata dan terbuka untuk kesempatan magang, kerja, maupun kolaborasi di bidang Data Science dan Backend Development.

Hi, I'm Arta, a Data Science student at Politeknik Elektronika Negeri Surabaya (PENS). I'm driven by one simple question: how can data become genuinely useful to people? That question led me to learn two things at once: data analysis and backend engineering.


I believe an accurate model isn't enough if nobody can use it. That's why I work on projects end-to-end: cleaning and understanding the data, building the model, wrapping it in an API, and deploying it to the cloud with Docker so anyone can try it live.


I'm currently diving deeper into integrating Large Language Models into real applications, and I'm open to internships, full-time roles, and collaborations in Data Science and Backend Development.
